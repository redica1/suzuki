# 스즈키 회원관리 — 앱스크립트 코드 (gas/member)

학원 · 교사 · 학생 · 연회비 명단을 정리하는 관리자 화면. 캠프 접수(gas/camp)와 같은 방식으로 운영해요.

| | 메인 | 테스트 (STG) |
|---|---|---|
| 선생님 (계정 만들기 · 로그인 · 내 정보) | https://redica1.github.io/suzuki/member/ | https://redica1.github.io/suzuki/member/?test |
| 관리자 | https://redica1.github.io/suzuki/member/admin.html | https://redica1.github.io/suzuki/member/admin.html?test |
| 시트 | 스즈키 회원관리 DB | [STG] 스즈키 회원관리 DB 테스트용 |

- **이 저장소는 공개**예요. 명단은 구글 시트에만 있고 여기에는 화면 코드만 있어요. 주민등록번호 · 계좌 · 집 주소는 시트에도 넣지 않아요(원본에서 읽지 않음).
- 고치는 순서: 이 폴더를 고침 → `python3 -I stamp.py`(빌드 번호 · 금지 글자 검사) → push → 도우미가 5분 안에 **STG 에만** 반영 → STG 에서 확인 → 도우미 `releaseNow` 로 메인 반영.

## 파일
- `Code.js` 서버 · `Index.html` 관리자 화면(`?page=admin`) · `Teacher.html` 선생님 화면(기본) · `files.json` 도우미가 받아 갈 파일 목록
- `appsscript.json.txt` 앱스크립트 매니페스트(처음 한 번 붙여넣기)
- `MemberDeploy.gs.txt` 「회원관리 자동 반영 도우미」 사본
- `stamp.py` 올리기 전 검사

## 처음 한 번 (STG · 메인 각각)
1. 시트 열기 → 확장 프로그램 → **Apps Script** (이름: `[STG] 스즈키 회원관리` / `스즈키 회원관리`)
2. 프로젝트 설정(톱니) → 「appsscript.json 매니페스트 파일 표시」 켜기 → `appsscript.json` 에 `appsscript.json.txt` 내용 붙여넣기
3. `Code.gs` 에 `Code.js` 내용, 파일 추가(HTML) `Index` 에 `Index.html` 내용 붙여넣기 → 저장 (처음 한 번만 손으로, 다음부터는 도우미가 함)
4. 함수 `setup` 실행 → 권한 허용 → 시트에 학원 · 교사 · 학생 · 연회비 · 설정 · 기록 탭이 생김
5. 시트 「설정」 탭: 관리자 비밀번호(노란 칸, 8자 이상). **STG 만** 「테스트 표시」 = 예 (원하면 「관리자 자동 로그인」 = 예)
6. 배포 → 새 배포 → 유형 **웹 앱** · 실행 = 나 · 액세스 = **모든 사용자** → 배포 ID(AKfy…)와 웹 앱 주소를 Claude 에게 전달
7. 웹 앱 주소를 열어 로그인 → 「설정 › 원본에서 불러오기」 (연회비 명단 → 학원 · 교사 · 학생 · 연회비)

## 자동 반영 도우미 (처음 한 번)
1. Apps Script 홈 → 새 프로젝트 `회원관리 자동 반영 도우미` → `Code.gs` 에 `MemberDeploy.gs.txt` 붙여넣기
2. 프로젝트 설정 → Google Cloud 프로젝트 → **1057506662611** (캠프 · 교사연수 도우미와 같은 suzuki-deploy) · 매니페스트 표시 → 파일 맨 위 MANIFEST 붙여넣기
3. `STG` · `PROD` 의 scriptId · deploymentId 채우기
4. `deployStgNow` 실행 → 권한 허용 → 로그 「배포 완료」 → `setupTrigger` 실행

## 시트 구조 (한 표에 한 종류, 한 줄에 한 건)
- **학원** 학원ID(A0001) · 학원명 · 구분 · 상태 · 원장교사ID · 교실대표번호 · 주소 · 계약체결일 · 확인 …
- **교사** 교사ID(T0001) · 이름 · 구분글자(원본의 A/B) · 원래이름 · 휴대전화 · 이메일 · 학원1~3(학원ID) · 직급 · 전공 · 회원구분(처음엔 「확인 전」) · 명단자격(원본 그대로) · 회비구분 · 캠프교수 · 내부외부 · 확인 …
- **학생** 학생ID(S0001) · 학원ID · 이름 · 구분글자 · 출생연도(·추정) · 전공 · 시작월 · 상태 · 담당교사ID · 확인 …
- **연회비** 대상(교사/학생) · ID · 년도 · 부과 · 납부 · 납부일 · 방식 (1년 = 1줄)
- **설정** · **기록**(누가 언제 무엇을 바꿨는지)
- 「확인」 = 확인 전 / 확인 필요 / 확인. 원본을 불러올 때 이상한 줄(열 밀림 · 명단에만 있는 학원 · 원장 못 찾음 · 이름만 있는 줄)은 「확인 필요」와 「확인메모」로 표시돼요.

## 구글 화면에서 주의 (캠프에서 겪은 것)
- 화면 스크립트 안에 `//` 를 쓰지 않기(구글이 주석으로 보고 지움 → 하얀 화면). `stamp.py` 가 막아요.
- 이모지 같은 4바이트 글자 쓰지 않기.
- 매니페스트 액세스가 `ANYONE_ANONYMOUS` 가 아니면 도우미가 배포를 멈춰요.

## 선생님 계정 (2026-10-28)
- 흐름: 이름 + 휴대전화로 명단에서 찾기 → 이메일(명단 이메일과 같으면 바로, 다르면 관리자 「승인 대기」) → 6자리 코드 → 소속·악기 「맞아요/달라요」 + 회원 구분 → 비밀번호 + 동의 → 계정 → 정산 정보 권하기(건너뛰기 가능).
- 명단에 없으면 같은 흐름으로 「가입 신청」(교사회원 / 연수교사회원 · 초급/중급) → 관리자 승인(새 교사 등록 또는 명단의 선생님에 연결) → 로그인.
- 시트: 계정(이메일 · 교사ID · 비번해시 · 솔트 · 상태 사용/대기/반려) · 요청(새 회원 / 이메일 확인 / 정보 수정). 비밀번호는 솔트 + SHA-256 5,000번(`S256x5000$…`).
- 정산 정보(계좌 · 우편물 주소)는 **별도 파일**(setup 이 만듦, 설정 「정산 정보 시트」). 영문 이름은 교사 탭.
- 메일을 보내므로 매니페스트에 `script.send_mail` 이 있어야 해요. 매니페스트를 바꾼 뒤 편집기에서 `setup` 을 한 번 실행해 권한 허용.
- STG 시험용 설정 「인증 코드 화면 표시」= 예 → 코드를 메일과 함께 화면에도 보여 줌 (메인은 꼭 아니오).
